# Project Brief: G-Rechka

## Core Identity
- **Name:** G-Rechka — клуб активного отдыха и сплавов
- **Location:** г. Киржач, Владимирская область, Россия
- **Website:** https://bobusbob.github.io/grechka33/ (GitHub Pages)
- **Type:** Одностраничный сайт (single-page landing)

## Core Requirements & Goals
1. **Онлайн-присутствие клуба** — информация об услугах, расписании, контактах.
2. **Бронирование и запись** — форма заявки, кнопки связи (WhatsApp, телефон, VK).
3. **Каталог услуг** — SUP-сплавы, SUP-туры, прокат SUP, мотособаки, мотобуксировщики, тюбинг (лето/зима).
4. **Мероприятия** — архив прошедших событий с фото и описанием.
5. **Визуальная связь с рекой и природой** — фоновый пейзаж, природная цветовая палитра.

## Target Audience
- Жители и гости г. Киржач и Владимирской области.
- Любители активного отдыха на воде (SUP, сплавы).
- Семьи с детьми и любители пикников (Dog-friendly, тюбинги, санки).
- Зимний активный отдых (мотособаки, мотобуксировщики).

## Key Constraints
- Один файл `index.html`, без сборщиков и фреймворков.
- Хостинг на GitHub Pages (статический сайт).
- Фоновое изображение весит ~619 КБ (сжато с 3,45 МБ).
