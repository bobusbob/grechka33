# Tech Context: G-Rechka

## Technology Stack
- **HTML5** — семантическая разметка (`<section>`, `<header>`, `<footer>`, `<form>`).
- **CSS3** — встроенный в `<style>` блок, CSS-переменные (`:root`), медиазапросы, `backdrop-filter`, `clamp()`.
- **Vanilla JavaScript** — встроенный в конец `<script>`, без библиотек и фреймворков.
- **Google Fonts** — Montserrat и Nunito через `@import` / `<link>`.

## Hosting & Deployment
- **Платформа:** GitHub Pages.
- **URL:** https://bobusbob.github.io/grechka33/
- **Репозиторий:** `bobusbob/grechka33` (предположительно).
- **Сборка:** отсутствует (загрузка файлов напрямую).

## Media Assets
- Фоновое изображение: `img/Фон лес река.jpg`, JPEG, 2000×1333, ~619 КБ.

## Constraints & Dependencies
- Требуется интернет для загрузки Google Fonts.
- Требуется поддержка CSS Grid/Flexbox и `IntersectionObserver` в браузере.
- Нет CMS, нет базы данных.
