# System Patterns: G-Rechka

## Architecture
Одностраничный сайт (single-page), всё содержимое в одном файле `index.html`. Нет бэкенда, нет сборщика, нет пакетного менеджера.

## File Structure
```
grechka33/
├── index.html          # Единственный HTML-файл (CSS в <style>, JS в конце <script>)
├── img/
│   └── Фон лес река.jpg # Фоновое изображение (сжато, 619 КБ)
├── memory-bank/        # Cline Memory Bank (этот каталог)
└── .git/
```

## Design System
- **Цвета:** `--fd:#1b3d2f` (тёмно-зелёный), `--fm:#2f624b` (зелёный), `--rb:#2a91ad` (голубой), `--gold:#f0b354` (золото), `--bg:#faf6ee` (песочный), `--tx:#1d2c24` (текст), `--mu:#506359` (вторичный текст).
- **Шрифты:** Montserrat (заголовки, 600/700/800), Nunito (основной текст, 400/500/600/700) через Google Fonts.
- **Иконки:** Встроенный SVG-спрайт (`<symbol id="i-*">` в `<defs>`).
- **Вёрстка:** Flexbox + CSS Grid, медиазапросы на 1120px, 1024px, 768px.
- **Секции:** `.hero`, `.about`, `.services`, `.events`, `.contacts`, `.footer`.
- **Карточки:** `.scard` (услуги), `.ecard` (мероприятия) с hover-эффектами (подъём + тень).

## JavaScript Patterns
- Фотографии подгружаются через `data-img` атрибуты и объект `IMG` (base64 превью).
- Фильтрация услуг по сезону (`data-sf`) и мероприятий по году (`data-y`) — переключение классов `.hidden`.
- `IntersectionObserver` для анимации `.reveal` блоков при скролле.
- Липкая навигация с подсветкой активной секции при скролле.
- Форма бронирования формирует ссылку WhatsApp (`wa.me`) и открывает её в новой вкладке.
